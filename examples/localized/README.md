# Example projects

Choose `zh_TW`, `zh_CN`, `ja` or `en`, then open `sample.advdb`, `branches.advdb` or `nvl.advdb`.

Keep each project beside its matching `_assets` folder. Use Save as before editing a bundled demo.
The same permanent dialogue IDs are intentionally used in each language version.
Background images are original solid-color placeholders. No operating-system fonts are included.
