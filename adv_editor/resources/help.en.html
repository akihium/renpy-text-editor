Getting started

Choose your language in the launcher, then open a recent project, create a project, or try a Sample. Each Sample opens a fresh editable copy in the selected language. Your edits remain available in recent projects. New projects are saved in the folder you choose; exports start in that same folder.

Editing dialogue

Double-click a cell or start typing. Use a character ID in the character column; leave it blank for narration. Character management sets IDs, names, colors and ADV/NVL modes.

ShortcutAction
EnterFinish editing and move to the next row's character cell. At the last row, add a row.
Tab / Shift+TabNext / previous editable cell.
Shift+EnterLine break within the same dialogue.
{mod}+B / {mod}+I / {mod}+UBold / italic / underline the selected dialogue text.
{mod}+S / {mod}+Shift+SSave / save as.
{mod}+Z / {mod}+Shift+ZUndo / redo.
{mod}+C / {mod}+VCopy / paste text while editing, or multiple cells when the table is selected.
{mod}+Shift+C / {mod}+Shift+VCopy / paste table data.

The “＋ Add dialogue” button below the table also adds a row.

Selection and row height

Select cells by dragging, or select row numbers using Shift for a range and {mod} for separate rows. Set “Row height” and click “Apply to selected rows”, or drag the bottom edge of a selected row number to resize all selected rows. “Auto height” restores automatic sizing. Heights are remembered locally for each project and permanent dialogue ID.

Formatting and branching

The main-window buttons apply formatting directly. Visual mode shows the effect; source-tag mode shows the tags. Click-to-continue inserts a player-click wait. Chapter/section management and staging controls create branch targets, backgrounds and choices.

NVL mode

In Character management choose ADV (one line at a time) or NVL (page of text) for each character and for narration. ADV and NVL characters can coexist. Insert “Clear NVL page” where a new page should begin. In choice settings, enable “Show choices in NVL mode”; optionally clear the page after a choice. Try the NVL Sample from the launcher. The editor exports these instructions; the final presentation is controlled by your Ren’Py game's screens.

Export and labels

Click “Export .rpy”. Choose a named subfolder or save directly in the selected folder. For a Ren’Py game, select its game folder or a folder inside it. Fonts and images follow the selected location. Existing handwritten files are preserved. In chapter/section management the label prefix defaults to adv_; you can change it or leave it blank. Internal calls, jumps and choices update together; update references in handwritten scripts yourself.

Word and PDF support a custom title. Excel is also available from the File menu. Saved projects autosave every 5 seconds and back up every 5 minutes. The launcher, this Help window and About show the current version. About includes the author, GitHub link and MIT license.
