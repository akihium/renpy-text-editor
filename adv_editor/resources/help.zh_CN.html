开始使用

在启动界面选择语言，再打开最近项目、新建项目或 Sample。每次打开 Sample 都会按所选语言创建全新副本，可以自由修改，并从最近项目中继续编辑。新建项目保存在你选择的文件夹内；导出默认也使用该文件夹。

编辑台词

双击单元格或直接打字即可编辑。角色列填写角色代号，空白表示旁白。「角色管理」可以设置代号、显示名字、颜色以及 ADV/NVL 模式。

快捷键操作
Enter完成编辑，移到下一行角色列；最后一行会自动新增。
Tab / Shift+Tab切换到右／左边可编辑的单元格。
Shift+Enter在同一句台词中换行。
{mod}+B / {mod}+I / {mod}+U将选中的台词文字设为粗体／斜体／下划线。
{mod}+S / {mod}+Shift+S保存／另存为。
{mod}+Z / {mod}+Shift+Z撤销／重做。
{mod}+C / {mod}+V编辑时复制／粘贴文字；选中表格时复制／粘贴多行数据。
{mod}+Shift+C / {mod}+Shift+V复制／粘贴多行表格。

也可以点击表格下方的「＋ 新增台词」添加一行。

选择与调整行高

拖动选中多个单元格，或在左侧行号用 Shift 选择连续行、{mod} 选择不连续行。输入「选中行高」并点击「应用到选中行」；也可以拖动已选行的行号下边缘，同步调整所有选中行。「自动行高」恢复默认高度。行高按项目和永久台词 ID 保存在本机。

格式与分支

主界面的格式按钮可直接应用效果。视觉模式显示格式，原始标签模式显示完整标签。「点击后继续」插入等待玩家点击的标记。章节／段落管理和演出功能可建立背景、分支及选项。

NVL 模式

在「角色管理」中，可分别为每个角色和旁白选择 ADV（逐句对话）或 NVL（整页文字）。两种角色可以混用。在适当位置插入「NVL 清页」。编辑选项时勾选「以 NVL 模式显示选项」，并可设置选择后是否清页。启动界面的 NVL 示例可直接试用。编辑器负责导出指令；游戏中的实际样式由 Ren’Py 项目的 screen 决定。

导出与 Label

点击「导出 .rpy」，可以自定义子文件夹名称，或直接保存在所选文件夹。用于 Ren’Py 时，请选择游戏的 game 文件夹或其中的文件夹；字体和图片路径会同步调整，已有的手写文件会保留。章节／段落管理中的 label 前缀默认为 adv_，可以修改或留空。项目内的 call、jump 和选项会同步更新，手写脚本的引用请自行调整。

Word 和 PDF 可自定义标题；Excel 也可从文件菜单导出。已保存的项目每 5 秒自动保存，每 5 分钟备份。启动界面、Help 顶部和「关于」都显示版本号。「关于」包含作者、GitHub 链接和 MIT 许可证。
