使い始める

起動画面で言語を選び、最近のプロジェクト、新規作成、または Sample を開きます。Sample は選択言語の新しいコピーを作るため、自由に編集できます。編集したコピーは最近のプロジェクトから再開できます。新規プロジェクトは選択したフォルダーに保存され、書き出し先の初期値も同じフォルダーになります。

セリフを編集する

セルをダブルクリックするか、そのまま入力して編集します。キャラクター欄には ID を入力し、ナレーションは空欄にします。「キャラクター管理」で ID、表示名、色、ADV/NVL モードを設定できます。

ショートカット操作
Enter編集を確定し、次の行のキャラクター欄へ移動。最終行では新しい行を追加。
Tab / Shift+Tab右／左の編集可能なセルへ移動。
Shift+Enter同じセリフ内で改行。
{mod}+B / {mod}+I / {mod}+U選択文字を太字／斜体／下線にする。
{mod}+S / {mod}+Shift+S保存／名前を付けて保存。
{mod}+Z / {mod}+Shift+Z元に戻す／やり直す。
{mod}+C / {mod}+V編集中は文字、表の選択中は複数セルをコピー／貼り付け。
{mod}+Shift+C / {mod}+Shift+V表データをコピー／貼り付け。

表の下の「＋ セリフを追加」でも新しい行を追加できます。

複数行の選択と高さ

セルをドラッグして選ぶか、左の行番号を Shift で範囲選択、{mod} で個別選択します。「選択行の高さ」を入力して「選択行に適用」を押すか、選択した行番号の下端をドラッグすると選択行をまとめて変更できます。「行高を自動調整」で初期状態に戻します。行高はプロジェクトと永久セリフ ID ごとにローカル保存されます。

書式と分岐

メイン画面のボタンで書式を直接設定できます。ビジュアルモードでは効果を、タグモードでは完全なタグを表示します。クリック待ちのボタンはプレイヤーのクリックを待つタグを挿入します。章・段落管理と演出機能で背景、分岐先、選択肢を作成できます。

NVL モード

「キャラクター管理」で各キャラクターとナレーションを ADV（1行ずつ）または NVL（ページ表示）に設定します。ADV と NVL のキャラクターは混在できます。改ページする位置に「NVL ページをクリア」を挿入してください。選択肢の設定で「選択肢を NVL モードで表示」を有効にし、選択後にページを消すかも指定できます。起動画面の NVL サンプルで試せます。エディターは命令を書き出し、ゲーム内の見た目は Ren’Py プロジェクトの screen に従います。

書き出しとラベル

「.rpy 書き出し」で、名前付きサブフォルダーか選択フォルダーへの直接保存を選びます。Ren’Py ではゲームの game フォルダーまたはその中のフォルダーを指定してください。フォントと画像の参照先も更新され、既存の手書きファイルは保護されます。章・段落管理ではラベル接頭辞 adv_ を変更、または空欄にできます。内部の call・jump・選択肢は自動更新されますが、手書きスクリプトの参照は別途修正してください。

Word と PDF はタイトルを指定できます。Excel はファイルメニューからも書き出せます。保存済みプロジェクトは5秒ごとに自動保存、5分ごとにバックアップします。バージョンは起動画面、このヘルプ上部、「このアプリについて」に表示されます。「このアプリについて」には作者、GitHub、MIT ライセンスも記載しています。
