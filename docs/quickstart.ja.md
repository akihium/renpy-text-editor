# はじめに

1. パッケージ全体を展開してください。Windows ではフォルダー内の `RenPy Text Editor.exe`、macOS では `RenPy Text Editor.app` を起動します。
2. 表示言語を選びます。`examples/ja/branches.advdb` を開くと日本語の例を試せます。新規プロジェクトでは保存先を選びます。
3. プロジェクトを移動するときは `.advdb` と同名の `_assets` フォルダーを一緒に保持してください。サンプルを編集する前に「名前を付けて保存」を利用できます。
4. キャラクター ID、セリフ、メモを入力します。Tab で次のセル、Enter で次のセリフ、Shift+Enter で改行します。書式・保存・元に戻す操作は Windows では Ctrl、macOS では Command を使います。
5. 章／セクション管理で分岐先を作り、選択肢の移動先に指定します。背景やフォントも追加できます。「テキストのみ」は演出を削除せずに非表示にします。
6. Ren’Py の `game` フォルダーに出力します。生成対象は `adv_generated` のみです。手書きの `label start` から `call adv_opening` で呼び出してください。
7. Word／PDF 出力ではタイトルとセリフ ID の有無を指定できます。RPY の ID 設定は独立しています。

オフラインで動作します。Ren’Py SDK やゲーム内プレビューは含みません。出力後はお使いの SDK で確認してください。実行ファイルは商用の開発者証明書による署名・公証を行っていません。
