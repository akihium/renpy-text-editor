## Ren’Py Text Editor 0.1.0

An offline dialogue editor for visual novel writers, with Windows x64 and macOS Apple Silicon packages.

### Included

- Four-column dialogue table with live Ren’Py preview, character, dialogue and notes.
- Visual formatting, imported fonts, click-to-continue and timed wait tags.
- Character IDs, display names and colors, with automatic reference updates when IDs change.
- Chapters, sections, copies, merges, background cues and branching choices.
- SQLite projects, autosave, asset-aware backups and search/replace.
- Ren’Py, Excel, Word and PDF exports, custom document titles and optional dialogue IDs.
- English, 日本語, 简体中文 and 繁體中文 interfaces.
- Four localized example sets in `examples/en`, `examples/ja`, `examples/zh_CN` and `examples/zh_TW`.

### Downloads

- **Windows**: extract `RenPy Text Editor-Windows-x64.zip` completely, then launch the EXE inside the folder.
- **macOS Apple Silicon**: extract `RenPy Text Editor-macOS-arm64.zip`, then open the app inside the folder.
- **Source**: use the source archive or clone the repository. License: MIT; dependencies retain their licenses.
- Verify archive integrity using `SHA256SUMS.txt`.

Both application packages include examples, quick-start guides and third-party license notices. These are portable builds, not signed installers. No system fonts or Ren’Py SDK are included. Use your own Ren’Py SDK to lint and test game scripts.
