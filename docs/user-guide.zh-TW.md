# Ren’Py 文本編輯器 Ren’Py Text Editor

完全離線的繁體中文 Ren’Py 台詞編輯器 MVP。Python 3.11+、PySide6、SQLite、openpyxl、python-docx、ReportLab，支援 Apple Silicon。

## 啟動

在專案資料夾的終端機執行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py examples/localized/zh_TW/sample.advdb
```

本次開發環境已建立 `.venv`，可直接執行最後一行。若專案位於 iCloud，建議以 `./scripts/run_macos.sh examples/localized/zh_TW/branches.advdb` 啟動；腳本會修正可能再次附加的 Qt 外掛隱藏屬性。macOS 內建的 Python 3.9 不適用；請使用 Python 3.11 以上版本。首次安裝需要網路，程式運行不需要。若在 iCloud 資料夾安裝後遇到 Qt 找不到外掛，請執行 `chflags -R nohidden .venv` 後重試；本次環境已修正。

## 使用流程

1. 開啟範例，或點主介面「新增專案」，立即選擇 `.advdb` 儲存位置。程式會建立同層 `<專案名>_assets` 素材資料夾。日後可用「另存／變更位置」儲存到其他資料夾，已匯入的字體及圖片會一起複製。
2. 點主介面右上方「角色管理」，以三欄表格設定角色代號、實際顯示名字、角色顏色。顏色可點「選色」或輸入 `#RRGGBB`。代號可以改名，儲存前會檢查重名，並同步更新所有台詞的角色引用；使用中的角色不可刪除。主表格角色欄顯示名稱及代號，編輯時填代號，空白代表旁白。右上方「角色欄背景色」可開關背景套色，關閉不會清除角色顏色；開關狀態會保留。
3. 雙擊儲存格或直接輸入。Tab / Shift+Tab 在三個可編輯欄位移動，略過唯讀原始碼欄。Enter 完成編輯並跳到下一行角色欄，最後一行會新增台詞。Shift+Enter 在台詞內換行。
4. 視覺模式中選取台詞文字後，直接點主介面工具列的粗體、斜體、底線、字號或文字顏色；也可使用 ⌘B / ⌘I / ⌘U。再次點粗體／斜體／底線可取消該格式。未選取文字時會設定後續輸入格式。「插入等待」使用旁邊的秒數，在游標位置插入等待提示。⌘Z / ⌘⇧Z 復原重做。儲存格編輯中優先復原該儲存格文字，完成編輯後可復原整體操作。
5. 點主介面「章節／段落管理」新增或編輯段落。可選擇既有章節，也可直接輸入新章節名稱（中英文皆可）；英文段落 ID 可自訂，例如 `chapter02_opening`，匯出為 `adv_chapter02_opening`。頂部下拉選單切換段落。管理表格中可多選後複製、刪除、合併、變更章節或上／下移動；按「套用」才寫入目前專案，也可按取消放棄。套用後可用 ⌘Z 復原。
6. 選取台詞列後 Option+↑ / ↓ 排序；永久台詞 ID 不改變。「編輯」可新增或刪除台詞。
7. 搜尋涵蓋所有章節的角色 ID、台詞及備註；全部取代只改台詞及備註，並支援復原。
8. 「檔案 → 匯出 Ren’Py」選擇遊戲的 `game` 資料夾。只產生或更新 `adv_generated/characters.rpy` 與 `adv_generated/dialogue.rpy`。此子資料夾由本程式專用，勿放手寫內容。

## 文字與剪貼簿

- 視覺模式可直接編輯富文字，包含粗體、斜體、底線、絕對字號與十六進位顏色。點進台詞或選取文字都不會顯示標籤；只有「原始標籤模式」的台詞欄顯示代碼。左側唯讀 Ren’Py 原始碼預覽持續顯示匯出結果。
- `{w=0.5}` 在視覺模式顯示為「（等待 0.5s）」提示，自訂標籤與速度指令顯示為可刪除的提示物件，並保留原始內容。它們不會被當成普通文字匯出。視覺模式不執行 Ren’Py 動畫或自訂標籤。原始模式中 `{` 的字面值請使用 Ren’Py 的 `{{`；視覺模式直接輸入 `{` 即可。
- 原樣檢視／切換模式不會改寫原始標籤。視覺編輯後會將等效格式重新序列化成 Ren’Py 標籤（順序可能正規化），未知標籤保留於提示物件中。視覺編輯器內複製貼上會保留格式與提示物件。
- `[` 預設當作字面值匯出，避免意外插值；MVP 不執行台詞中的 Python 表達式。引號、反斜線、百分比及換行會跳脫。
- 表格選取後 ⌘C / ⌘V 或「編輯 → 複製／貼上表格」（⌘⇧C / ⌘⇧V），支援 tab 分欄、換行分列與引號包覆的多行儲存格。從角色欄開始貼上最多三欄：角色 ID、台詞、備註。原始碼欄不參與複製。
- 台詞編輯中一般貼上多行文字保留在同一儲存格；要貼成多行表格，先完成編輯，再用貼上表格。
- Excel 匯出包含「台詞」「角色」兩張工作表。依範本修改後匯入會完整取代目前內容，可復原。保留台詞 ID 與段落 ID；新增台詞可留空台詞 ID。角色 ID 與段落 ID 必填。「角色」工作表新增顏色欄，仍可匯入只有兩欄的舊版 Excel。舊版 `.advdb` 開啟時會自動新增角色顏色欄位，不更改台詞 ID。全空段落應保留至少一行空台詞，以利 Excel 往返。

## 儲存與備份

選擇資料庫後每 5 秒自動儲存，⌘S 立即儲存。每 5 分鐘、另存及關閉時透過 SQLite backup 建立一致快照，放在同層 `<檔名>_backups`，保留最新 20 份。復原備份時直接開啟備份 `.advdb`，再另存新檔。新專案尚未選擇位置前不會自動儲存。每次資料更新使用交易，驗證失敗不覆寫現有資料。備份會一併複製該快照使用的字體與圖片到同名素材資料夾；復原／搬移專案請保留 `.advdb` 與同名 `_assets` 資料夾。

## Ren’Py 接入

在**手寫**的 `script.rpy` 中呼叫：

```renpy
label start:
    call adv_opening
    return
```

匯出檔使用 `label adv_<段落ID>`、原生 `call` / `return`、`aki "台詞" id d_<永久ID>`。角色定義集中生成，與翻譯系統相容；將程式生成的檔案放入 game 後，再於 Ren’Py Launcher 使用「產生翻譯」。不要在手寫檔案重複定義同名角色或 label。

格式依官方文件：[Translation](https://www.renpy.org/doc/html/translation.html)、[Text](https://www.renpy.org/doc/html/text.html)。匯出測試檢查語法與資料保留；仍應以你的 Ren’Py SDK 執行「檢查腳本（Lint）」及遊戲驗收，特別是自訂標籤。本專案未附 Ren’Py SDK。

## 測試與打包

```sh
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
./scripts/build_macos.sh
```

測試使用真正的 Qt 編輯元件與 QTest 按鍵事件，涵蓋導航、格式、換行、貼上、排序、復原、SQLite、備份、Excel 與 Ren’Py 匯出。打包結果是 `dist/RenPy Text Editor-macOS-arm64.zip`，內含已做 ad-hoc 簽章的 `.app`。請解壓縮到本機非 iCloud 資料夾後開啟（建議「應用程式」）。打包腳本使用 `/private/tmp` 暫存資料夾完成並驗證簽章，以免 iCloud 附加 FinderInfo 導致簽章失敗。公開散布需另行 Developer ID 簽章與公證。

## MVP 限制

目前已支援常用文字格式的直接視覺編輯；未支援的 Ren’Py 標籤顯示為提示物件。已支援基礎演出指令與選項跳轉，尚未包含演出時間軸、條件式選項、變數計算或 Ren’Py 引擎內預覽。段落中的台詞與演出依資料列順序執行，jump 或選項跳轉會轉移到目標段落；段落結尾仍可設定 call 並 return。請避免建立間接遞迴 call。資料庫應由一個編輯器視窗使用。

## 章節／段落管理規則

- 英文段落 ID 只能使用英數字及底線，以英文字母或底線開頭，且專案內不可重複；不需要輸入自動加上的 `adv_` 前綴。
- 「編輯名稱／ID」可修改章節、段落名稱、英文 ID 和結尾 call；修改 ID 時同步更新專案內的 call，台詞 ID 不改變。手寫演出檔案或其他外部檔案中的 label 引用需要自行同步修改。
- 複製選取段落會建立 `_copy` 副本，並分配全新的永久台詞 ID。同批複製的段落若互相 call，副本會指向對應的副本。原段落與 ID 保持不變。
- 刪除選取段落會清除其他段落結尾指向它們的 call。如果仍有選項或資料列 jump／call 引用被刪段落，會拒絕操作，請先調整那些引用。專案至少保留一個段落。管理視窗內的操作僅修改草稿，按套用前可取消全部變更。
- 批次合併依表格由上到下串接台詞，保留第一段的名稱、英文 ID 與章節，以及最後一段的 call，所有既有台詞 ID 保持不變；指向被併入段落的專案內 call 改指向第一段。
- 合併時，中間段落若有 call，僅允許指向下一個待合併段落；其他流程會顯示原因並保留原資料，讓你先調整 call 後再合併。最後一段不能 call 回待合併段落，以免合併後呼叫自身。
- 「變更章節」可將多個選取段落移入既有章節或新的章節名稱。選取同章節全部段落後套用新名稱即可替章節改名。

## 點擊後繼續與字體

- 在同一句的分段位置放游標，點「點擊後繼續」，插入 Ren’Py 原生 `{w}`。例如 `前半句{w}後半句` 會先顯示前半句，等待玩家點擊後再顯示後半句；台詞仍使用同一個永久 ID。視覺模式顯示「（點擊後繼續）」。
- 「匯入字體」支援 TTF／OTF，會自動複製到 `<專案名>_assets/fonts`；不需要事先把原始字體放在專案旁，也不依賴原始檔案的位置。從字體下拉選單選擇後，套用到選取文字；未選取時套用到後續輸入。
- 字體標籤使用穩定的相對路徑：`{font=adv_generated/fonts/font_<內容雜湊>.ttf}…{/font}`。匯出 Ren’Py 時字體會複製到 `game/adv_generated/fonts`。編輯器中的字族名稱只用於預覽，遊戲使用實際匯入的字體檔案。
- 不同字體支援的字元不同。Word 文稿記錄字族名稱，未嵌入字體檔；在其他電腦閱讀時可能需要安裝該字體。PDF 對支援的 TrueType 字體嵌入子集；不支援的 OpenType 輪廓格式改用預設字體，匯出狀態會提示。

## 背景演出與分支

1. 點「新增演出」，選擇背景切換、顯示／隱藏圖片或單獨轉場。可匯入圖片，也可填寫遊戲裡已存在的 Ren’Py 圖片標籤，例如 `bg classroom`。
2. 圖片自動複製到 `<專案名>_assets/images`，匯出時複製到 `game/adv_generated/images`，並集中產生 `image` 定義。支援 PNG／JPEG／WebP。轉場提供淡入淡出 `dissolve`、黑場淡入 `fade` 與立即 `None`。
3. 演出資料列插入在目前列下方。雙擊演出列可編輯；可使用原有的上下移動與刪除台詞列功能調整位置。Enter／Tab 的文字輸入導航會略過演出列。
4. 點「只顯示文本」會隱藏背景與流程指令列、唯讀原始碼欄，以及台詞內的等待／自訂標籤提示。選項文字保留，跳轉代號暫時隱藏；關閉後完整恢復，不會刪除資料，也不影響匯出。
5. 分支使用現有段落：先在「章節／段落管理」新增分支段落，再點「新增選項／分支」，逐項填寫選項文字並選擇目標段落。匯出原生 `menu` 與 `jump adv_<英文ID>`；也能插入獨立 jump／call／return 資料列。
6. 修改段落 ID 時，也會同步更新選項與資料列 jump／call 的目標；批次複製段落時，副本內的分支引用會指向對應副本。

可開啟 `examples/localized/zh_TW/branches.advdb` 試用背景、點擊等待與兩個選項。這個範例的背景只是單色占位圖，示範素材管理。

## Word PDF 與 Excel

主介面頂部可直接匯出 Word 或 PDF，包含章節、角色、台詞、備註、永久 ID 與演出／分支提示。常用文字格式轉成文件格式，不會把 `{b}` 之類代碼當台詞印出。文件是供閱讀校對的輸出，不能作為專案回匯。

Excel 新增資料列類型、轉場、選項 JSON，以及字體／圖片資料表，保留原有八欄格式的匯入相容性。含素材的 Excel 會帶同名 `_assets` 資料夾，搬移或匯入時請一起保留；選項可直接在軟體介面編輯，不需手動修改 JSON。

打包後匯出檢查（開發驗證用途）：`<app內的可執行檔> --verify-exports <輸出資料夾>`，會實際產生 SQLite、Excel、Ren’Py、Word、PDF 與 `result.json`，不開啟編輯視窗。

## 台詞 ID 顯示與匯出開關

- 主介面「顯示台詞 ID」只控制唯讀原始碼預覽與 ID 提示，預設隱藏；不會刪除專案內的永久 ID。
- 「RPY 包含台詞 ID」獨立控制匯出語法。關閉後輸出一般寫法 `aki "你好！"`，開啟則輸出 `aki "你好！" id d_...`。為保留既有專案的匯出行為，預設開啟；可隨時關閉。
- 若已建立 Ren’Py 翻譯檔，變更 ID 匯出設定後請重新檢查翻譯對應。
- Word／PDF 匯出前可輸入文件標題，並獨立選擇「文件包含台詞 ID」。預設依目前畫面的 ID 顯示開關決定。標題同時套用 PDF 首頁與 PDF 文件中繼資料；同一視窗會記住上次成功匯出的標題。

## 介面語言與軟體名稱

主介面右側「介面語言」提供 English、日本語、简体中文、繁體中文，即時切換並記住偏好。語系檔內建於程式，完全離線。選單、工具列、管理對話框、欄位名稱、操作訊息及標籤提示均提供翻譯。台詞、角色名字、備註、章節內容、程式標籤及 Excel 固定欄位結構保持原樣。

軟體顯示名稱為「Ren’Py 文本編輯器／Ren’Py 文本编辑器／Ren’Py Text Editor」，macOS 安裝包改名為 `RenPy Text Editor.app`。沿用原有專案格式與設定位置，舊 `.advdb` 可直接開啟。
